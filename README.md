# Dropper Output Controller Mod

## 📋 Übersicht
Eine Minecraft Fabric Mod für **Minecraft Java 1.21.4** und **Fabric Loader 0.16.9+**, die es dir ermöglicht, Dropper-Ausgaben mit einem GUI-Menü zu steuern.

## ✨ Features
- ✅ GUI-Menü mit der Taste **Ü** (oder **U**) öffnen
- ✅ 2 Dropper auswählen (Dropper 1 & 2)
- ✅ 9 verschiedene Output-Items auswählen (1-9)
- ✅ Mehrsprachig (Deutsch + Englisch)
- ✅ Fabric 0.19.5 kompatibel

## 📦 Installation
1. Fabric Loader 0.16.9+ herunterladen und installieren
2. Diese Mod in den `mods` Ordner kopieren
3. Minecraft starten und "Dropper Output Controller" sollte geladen sein

## 🎮 Bedienung
1. Drücke **Ü** um das Menü zu öffnen
2. Wähle Dropper 1 oder 2
3. Wähle Output Item 1-9
4. Klicke "Set Output" zum Bestätigen
5. Klicke "Close" oder drücke ESC zum Schließen

## 📋 Anforderungen
- **Minecraft:** 1.21.4 (Java Edition 26.2)
- **Fabric Loader:** 0.16.9+
- **Fabric API:** 0.108.0+
- **Java:** 21+

## 🛠️ Kompilieren
```bash
./gradlew build
```

Die fertige `.jar` Datei befindet sich in `build/libs/`
